How a skill works

Ask

The agent asks you for missing facts. It never invents numbers about your business; gaps become clearly marked placeholders.

Build

A deterministic Python script writes the native file: pptx, docx, xlsx with live formulas, PDF or HTML. No network, no API keys.

Check

The agent re-opens its own output and runs a QA checklist: overflow, empty placeholders, formula errors, numbers that disagree. Then it fixes them.

Install in 30 seconds

Claude Code plugin marketplace

/plugin marketplace add boardroomskills/boardroom-skills

Manual copy (any agent that reads SKILL.md)

git clone https://github.com/boardroomskills/boardroom-skills.git
cp -r boardroom-skills/skills/* ~/.claude/skills/

Codex: ~/.codex/skills/ or ~/.agents/skills/. Cursor: .cursor/skills/. Check your version's docs if a skill does not appear.

Honest limitations

  • You get a strong first draft, not a finished document. Review every output and check numbers against your source data.
  • Quality depends on your inputs and on the agent model you run. Thin briefs give thin decks.
  • Not professional advice: the contract review is not legal advice, the model is not a valuation, the CMA is not an appraisal.
  • A few fixed themes per skill and system fonts only. Deep brand matching means editing the templates.
  • English-first. Developed and tested on Linux with Python 3.9+; macOS and Windows are less tested.
  • Some QA and preview steps need LibreOffice and poppler installed.

FAQ

Is this just prompts?

No. Each skill includes tested Python (python-pptx, openpyxl, reportlab, python-docx, matplotlib) that builds the file, plus instructions that tell the agent how to drive it and how to check the result.

Which agents does it work with?

Built and tested mainly with Claude Code. The format is the open Agent Skills layout (a folder with SKILL.md), which Codex and Cursor can also load.

Can I edit the files it makes?

Yes. Decks, Word files and spreadsheets are native editable files with real charts and live formulas, not screenshots.

Can I use the output for clients?

Yes. Files you generate are yours.

Where does my data go?

The scripts run locally and make no network calls. Your agent sends your conversation to its model provider as usual.

How does PRO access work?

Polar takes the payment and automatically invites your GitHub account to the private repository. Cancelling a subscription removes access; a lifetime purchase keeps it.

Can I redistribute the skills?

The free skills, yes, under MIT. PRO is single-user with no redistribution.
