What are Claude Agent Skills, and how do you install them?

An Agent Skill is a folder of instructions and scripts that your coding agent loads only when a task needs it. Here is what is inside one, where to put it for Claude Code, Codex and Cursor, and what to check when it does not show up.

By Boardroom Skills · Updated 2026-11-09 · About 5 min read

Short version: a skill is a folder with a SKILL.md file, plus optional scripts and templates. Your agent reads only the skill’s short description until a task matches, then loads the full instructions. To install one, copy the folder into your agent’s skills directory and restart. Agents differ on exact paths, so check your version’s documentation if a skill does not appear.

What an Agent Skill is

An Agent Skill is a packaged procedure for an AI coding agent. Instead of pasting a long prompt every time you want a board deck or a code review, you save the procedure once as a folder. The agent decides when to use it, follows it, and runs any scripts that come with it. Anthropic introduced the format for Claude, and it has since been published as an open standard, which is why the same folder layout can be read by Claude Code, and by other agents such as Codex and Cursor.

What is inside a skill folder

investor-pitch-deck/
  SKILL.md           instructions + a name and description
  scripts/           code the agent runs (build, QA, preview)
  templates/         themes, config templates
  examples/          sample input and output
  requirements.txt   Python dependencies, if any

The only required part is SKILL.md. It starts with a small block of metadata and then plain markdown:

---
name: investor-pitch-deck
description: Build a 13-slide investor pitch deck (.pptx) with native,
  editable charts. Use when a founder asks for a pitch deck...
---

# Investor pitch deck
## Workflow
1. Collect inputs. Never invent numbers...

The description is the most important line. It is how the agent decides whether the skill applies. A vague description means the skill never triggers; a description that is too broad means it triggers when you did not want it.

How a skill loads (and why it is cheap)

Agents generally load skills in stages. At startup they read only each skill’s name and description, which costs very little. When your request matches, the agent reads the full SKILL.md. Supporting files and scripts are read or run only if the instructions call for them. This is why you can install dozens of skills without filling the model’s context window. The details differ between agents, but the idea is the same.

Skills versus prompts, MCP servers and plugins

  • Prompt: text you type each time. A skill is a saved, reusable one with code attached.
  • Custom instructions or CLAUDE.md: always-on guidance for a project. Skills load on demand.
  • MCP server: gives the agent tools to reach external systems such as a database or an API. A skill is procedural knowledge and local scripts; the two can work together.
  • Plugin: in Claude Code, a way to distribute and install bundles that can include skills, through a marketplace.

How to install a skill

Option A: Claude Code plugin marketplace

If the skill repository is set up as a plugin marketplace, installation is two commands inside Claude Code. For the free Boardroom Skills:

/plugin marketplace add boardroomskills/boardroom-skills
/plugin install boardroom-skills@boardroom

Option B: Copy the folder (works everywhere)

This is the most portable method. Skills in a personal directory are available in every project; skills in a project directory travel with that repository.

git clone https://github.com/boardroomskills/boardroom-skills.git
mkdir -p ~/.claude/skills
cp -r boardroom-skills/skills/* ~/.claude/skills/

Use .claude/skills/ inside a project to scope them to that project and share them with your team through git.

AgentPersonal directoryProject directory
Claude Code~/.claude/skills/.claude/skills/
Codex~/.codex/skills/ or ~/.agents/skills/.agents/skills/
Cursor~/.cursor/skills/ (it also reads ~/.claude/skills/).cursor/skills/

Treat the Codex and Cursor rows with care. Their skills support has changed more than once and sources disagree on exact paths, so confirm against the current documentation for your version. Claude Code is where this has been tested most.

Option C: A community installer

Some community tools install skills for several agents at once, for example an npx-based CLI. Check what a tool does before running it, as you would with any package that writes into your home directory.

Option D: Claude on the web and desktop

Claude’s apps also support skills in some plans, typically by uploading a skill folder as a zip file in settings. Availability depends on your plan and changes, so check Anthropic’s current help pages.

After copying: three things people forget

  1. Restart the agent (or start a new session) so it re-scans the directory.
  2. Install dependencies. If the skill ships Python scripts, run pip install -r requirements.txt from its folder. Without it, the first build fails with an import error. Some skills also use external programs: the Boardroom Skills previews use LibreOffice and poppler for rendering.
  3. Folder structure. Copy the skill folder itself, so the path is ~/.claude/skills/skill-name/SKILL.md, not ~/.claude/skills/SKILL.md.

How to trigger a skill

Two ways. Ask for the task in plain words (“build a seed pitch deck from notes.md”) and let the agent match the description. Or call the skill by name if your agent supports it; in Claude Code a plugin skill can be invoked like /boardroom-skills:investor-pitch-deck build a seed deck from notes.md. If nothing happens, ask the agent which skills it can see.

If a skill does not show up

SymptomCheck
Agent never uses itIs SKILL.md at the top of a folder inside the skills directory? Does the name match the folder? Is the frontmatter valid (three dashes above and below)?
Not listed after copyingRestart. Check you used the directory your agent version actually scans.
It loads but the build failsPython version and pip install -r requirements.txt. Read the error; it is usually a missing package.
It triggers at the wrong timeTighten the description, or call it by name.

Safety: skills run code

A skill can instruct the agent to run commands and scripts on your computer. Treat an unknown skill like an unknown program. Read the SKILL.md and the scripts before installing, prefer ones with a clear licence and history, and be wary of any that make network calls or ask for credentials you did not expect. Boardroom Skills scripts, for what it is worth, run locally with no network access and need no API keys, and you can verify that by reading them in the open repository.
